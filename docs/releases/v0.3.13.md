# v0.3.13 — Reminders for manual backups and checks

- Add independent daily, weekly, and 30-day reminder options in Preferences, off by default.
- Notify without launching a backup or check; clicking a notification opens the application.
- Pause reminders during automatic schedules and active operations, catch up after login, and limit overdue repeats to once a day per task.
- Persist reminder state per desktop user, source, repository, and check scope. Successful observed runs reset the interval; failed or incomplete runs do not.
- Leave existing backup and verification schedules unchanged.
