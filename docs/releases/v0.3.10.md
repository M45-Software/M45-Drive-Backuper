# v0.3.10 — Snapshot checks and visible tray activity

- Default to checking only the most recent completed snapshot; keep timing manual only.
- Allow manual checks of the latest snapshot, a selected completed snapshot, or the whole repository.
- Save the check scope independently of timing; one-off manual selections do not change the saved schedule.
- Read snapshot data with Borg dry-run extraction without restoring files. Keep whole-repository verification as a separate full Borg check.
- Preserve separate snapshot and whole-repository success history.
- Animate the tray icon with a blue backup arrow or purple check magnifier; show the actual active operation when a backup is waiting behind a check.

Snapshot checks still read shared unchanged data required by that snapshot. They do not certify old-only data or repository-wide structure.
