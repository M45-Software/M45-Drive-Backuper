# M45 Drive Backuper 0.3.6

- Text and table headers use foreground colors matched to their desktop palette backgrounds, improving dark theme readability.
- Checkboxes have visible outlines and checkmarks in both light and dark themes while retaining native keyboard behavior and accessibility.
- Disabled controls use the desktop palette's disabled text colors instead of low-contrast border colors.
- Switching the desktop theme refreshes the existing window, including styled controls, without restarting the app.
- UI regression coverage checks repeated light/dark palette changes and checkbox visibility. The screenshot capture tool supports both themes and live theme switches.

Installation and opening the app do not modify the backup configuration or start a backup. This preview release continues to adapt the supported existing local Borg backup job; it does not restore files or create bootable disk images.
