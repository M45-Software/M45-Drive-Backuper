# M45 Drive Backuper 0.3.5

- A persistent sidebar, clearer status overview, and separate source, destination, and schedule sections replace the crowded tab layout.
- Activity now shows local timestamps, severity icons, sources, and multiline messages, with search, warnings/errors filtering, and a plain-text view.
- The README includes high-resolution dark-mode screenshots of every page and a repeatable capture command.
- Ubuntu 24.04 amd64 packages can be distributed through the shared signed M45 Software APT repository. Release automation verifies the exact published package checksum and uploads through a dedicated, package-restricted receiver; the signing key stays on the server.

Installation and opening the app do not modify the backup configuration or start a backup. The app continues to adapt the supported existing local Borg backup job; it does not restore files or create bootable disk images.
