# v0.3.8 — Optional backup integrity verification

- Add Check now and Stop check under Saved backups, using full Borg data and archive verification.
- Default to manual only; offer after-backup, daily, weekly and monthly checks as explicit opt-ins.
- Run checks through systemd, serialize them with backups, and persist independent results and the last successful verification time.
- Report warning, failure and interrupted checks without replacing backup-attempt results or claiming success.
- Installation discovers the new service/timer without enabling them or running a check.

Verification checks stored integrity. Source coverage and restoration testing remain separate tasks.
