# v0.3.11 — Browse snapshots and recover files

- Add Browse and recover for a selected completed snapshot, with lazy folder navigation, name filtering, and paging.
- Authenticate once for each snapshot browser session; cache only metadata for fast subsequent navigation.
- Recover selected files or whole folders into a fresh user-owned subfolder under ~/Recovered Files by default, or another chosen destination.
- Preserve literal/non-text filenames and recover hardlinked files even when their original master path was not selected.
- Keep recovery isolated from live source files, validate selected paths and archive identity, and extract as the desktop user with safe tar filtering.
- Report incomplete/partial recovery honestly and offer Open recovered folder.

Existing verification defaults remain manual only and most recent completed snapshot only.
