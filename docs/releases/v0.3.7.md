# M45 Drive Backuper 0.3.7

- Start login sessions quietly in the tray using the default `--autostart` entry, even before the system tray is ready.
- Add **Open window at login** in Preferences for users who want the overview at startup.
- Keep repeated login launches from raising an existing window; manual launches still open it.
- Persist observed completed backup attempts and their diagnostics across reboots, scoped to the source and repository. New attempts take precedence over saved history.
- Show a neutral waiting state when no prior attempt details are available, instead of a warning solely because systemd reset its runtime state at boot.

Validated with backend and history tests, Qt UI checks, isolated desktop startup checks for both preference values, and Debian package construction.
